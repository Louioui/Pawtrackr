# CloudKit record types that the Production schema of iCloud.PartnerShipWithMedia.Pawtrackr
# must contain before an archive ships. There is one CD_<Model> line per entry in
# PawtrackrSchema.models (Pawtrackr/Core/Storage/Migrations.swift).
#
# ci_scripts/ci_pre_xcodebuild.sh fails every build if this list and PawtrackrSchema.models
# drift apart. On an archive with a CloudKit management token, it also fails when Production
# lacks one of these types, or lacks a field that Development has for one of them.
#
# Fields aren't listed here. The gate reads them from a live Development export, so run the
# DEBUG schema initializer after every model change (docs/icloud-validation.md).
#
# A field that only exists in Development, such as an abandoned experiment, can be excused
# with a line like the one below. Resetting the Development environment in CloudKit Console
# is the cleaner fix.
#   ignore CD_Client.CD_someAbandonedField
#
# PTSyncFailureReport, the public-database failure report type, isn't listed: this list
# only takes mirrored CD_ types, so the gate doesn't check it. Check it in Production by
# hand (docs/cloudkit/sync-failure-reports.md).
